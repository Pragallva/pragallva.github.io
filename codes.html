Code

Code and data analysis behind my papers, on GitHub.

  • heatwave-box-atlas
    Scripts that build the Heatwave Box Atlas: heatwave days per decade, surface-flux regimes, surface temperature and local wave activity for 18 regions in the MPI Grand Ensemble (historical and SSP3-7.0). Code
  • LWA-Blocking-2024
    Local wave activity analysis of Northern Hemisphere winter blocks, for Barpanda & Nakamura (J. Climate, 2025). Code
  • MJO-waves-mean-flow
    Wave–mean flow diagnostics of the Madden–Julian Oscillation and subtropical Rossby waves, for Barpanda et al. (J. Atmos. Sci., 2023). Code
  • rossby-blocking (fork of alphaparrot/rossby-blocking)
    The “traffic jam” model of atmospheric blocking, for Paradise et al. (J. Atmos. Sci., 2019). Code
  • Isca_Aquaplanet_experiments
    Idealized aquaplanet experiments with the Isca model and their analysis. Code
  • Isca (fork of ExeClim/Isca)
    Idealized general circulation model from the University of Exeter. Code
